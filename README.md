# 有機野菜の宅配 つちのね便｜サイトデータ

愛知・三河の農家が育てた有機JAS野菜を届ける、架空の通販サイト「つちのね便」（株式会社つちのね）です。
HTML・SCSS・JavaScriptで制作した静的サイトで、PC・スマホの両方に対応しています。

## 確認方法
`index.html` をブラウザ（Chrome推奨）で開いてください。
スマホ表示は、デベロッパーツールのデバイス表示（幅390pxなど）で確認できます。

## フォルダ構成
- `scss/` … SCSS（`style.scss` が各パーシャルを読み込みます）
- `css/style.css` … SCSSのコンパイル結果
- `js/main.js` … 全ページ共通のJavaScript
- `js/vendor/lenis.min.js` … スムーススクロール（Lenis 1.1.13）
- `data/products.json` … 商品データ（名前・価格・説明・写真）。`data/products.js` は同じ内容で、HTMLを直接開いたとき用です
- `images/photo/` … 写真（ChatGPTで生成）、`images/photo/fv/` … 切り抜きの野菜写真
- `images/illust/` … イラスト、`images/logo/` … ロゴ

## SCSSのコンパイル
```
npx sass scss/style.scss css/style.css --no-source-map
```
CSS・JSを更新したときは、各HTMLの `style.css?v=〇〇` `main.js?v=〇〇` の番号も更新してください（古いキャッシュが残らないように）。

## 主な機能
- **カート**：ブラウザ（localStorage）に保存し、ページを移動しても残ります。注文を確定すると空になります
- **定期便**：旬の野菜セット（小さめ・S・M・L）は、お申し込みページ・商品の詳細・カートで「今回のみ／定期便（隔週・毎週）」を選べます（通常価格から10%オフ）。定期便はカートに1つまでです
- **ログイン・マイページ**：デモのため、どのメールアドレス・パスワードでもログインできます。定期便のお休み・間隔の変更・解約を試せます
- **お問い合わせ・注文**：デモのため送信されません。公開時にフォーム・決済のサービスとつなぎます

- 直売所の営業時間・住所・地図、SNSのアカウント
